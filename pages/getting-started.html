DEVELOPER GUIDE

Start with the foundations.

Orestra is not yet a runnable cluster. The available Oreslang code covers pure scheduling and lifecycle decisions; Python fixtures/oracles are limited to conformance and offline tools.

Inspect and test the source

git clone https://github.com/orestra/orestra.git
git clone https://github.com/orestra/orestra-conformance.git
cd orestra-conformance
python3 scripts/run.py

Repositories may require GitHub organization access. The conformance command executes deterministic reference tests, not a live Kubernetes or Orestra cluster.

Explore the API contracts

Browse orestra-api for versioned schemas, gRPC messages and an OpenAPI draft. Browse orestra-state for compare-and-swap, watch cursor and lease test models.

What comes next

Oreslang HTTP server integration, a persistent transactional store, scheduler actors, OCI node agents and an actual three-node failure/recovery test. Until those exist, no production use is supported.
