BUILT ON DIFFERENT FOUNDATIONS

Orchestration is a concurrency problem.

01 /

Actor-owned control

Supervised actors own mutable controller state. Lightweight Tasks handle bounded parallel computations. No actor is required for every container.

02 /

Transactions over guesses

Scheduling proposals are speculative; authoritative reservations need atomic resource-version checks and fencing epochs.

03 /

Correct by construction

State machines, explicit resource generations, deterministic conformance models and failure-first testing shape the design.
